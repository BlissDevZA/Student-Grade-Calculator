# Student Grade Calculator

## About the Project
The Student Grade Calculator is a simple desktop application developed using Python and Tkinter. It provides a user-friendly graphical interface that allows users to enter student information and marks, calculate grades, and manage the input fields.

## Features
- Enter the student's name.
- Enter the student's mark.
- Calculate the student's grade.
- Display the calculated result.
- Clear the input fields for a new calculation.

## Technologies Used
- Python
- Tkinter

## How to Run
1. Download or clone this repository.
2. Make sure Python is installed on your computer.
3. Open the project folder in VS Code.
4. Run the Python application using the terminal:

```bash
python your_file_name.py
```

Replace `your_file_name.py` with the actual name of your Python file.
